Authentication

All API requests require authentication. You can authenticate using API keys or OAuth tokens.

API Key Authentication 
curl -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     https://api.cybercloak.com/v1/encrypt

Encrypt Image

Encrypt and hide a message within an image using steganography.

POST /api/v1/encrypt
Request Body
JSON Schema 
{
  "image": "base64_encoded_image_data",
  "message": "Secret message to hide",
  "password": "optional_password",
  "format": "png"
}
Response
Success Response 
{
  "success": true,
  "data": {
    "encrypted_image": "base64_encoded_result",
    "file_id": "uuid_string",
    "processing_time": 1.23,
    "security_score": 95
  }
}

Decrypt Image

Extract and decrypt a hidden message from an image.

GET /api/v1/decrypt
Request Parameters
Parameter Type Required Description
file_id string Yes File ID from encryption response
password string No Password used for encryption
Response
Success Response 
{
  "success": true,
  "data": {
    "message": "Extracted secret message",
    "file_id": "uuid_string",
    "processing_time": 0.87
  }
}

Python SDK

Use our Python SDK for easy integration.

Installation 
pip install cybercloak-sdk
Usage Example 
from cybercloak import CyberCloakClient

# Initialize client
client = CyberCloakClient(api_key="your_api_key")

# Encrypt image
result = client.encrypt_image(
    image_path="path/to/image.png",
    message="Secret message",
    password="optional_password"
)

print(f"Encrypted image saved to: {result['file_path']}")

# Decrypt image
decrypted = client.decrypt_image(
    file_id=result['file_id'],
    password="optional_password"
)

print(f"Decrypted message: {decrypted['message']}")

Error Codes

Common error responses and their meanings.

400
Bad Request

Invalid request parameters or missing required fields.

401
Unauthorized

Invalid or missing API key.

429
Rate Limited

Too many requests. Please wait before retrying.

500
Internal Server Error

Something went wrong on our end. Please try again later.
